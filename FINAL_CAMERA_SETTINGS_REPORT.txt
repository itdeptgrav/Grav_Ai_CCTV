2. SETTINGS STORAGE
--------------------------------------------------------------------------------
  Location : D:\GRAV_Project\grav-cctv\data\camera-settings.json
             (folder + file are created automatically on the first save;
              override with CCTV_SETTINGS_FILE for hosting)
  Format   : {"version": 1, "revision": 7, "updatedAt": "...+05:30",
              "cameras": {"nvr1:8": {"displayName": "HR Office", "displayOrder": 1}}}
             Only customised cameras are stored. No credentials, no RTSP URLs.
  Safety   : validate everything first, then write a temp file, fsync, and
             atomically replace (os.replace) under a lock; a crash mid-save keeps
             the previous file intact. An unreadable file is kept as
             camera-settings.json.corrupt-<time> and defaults are used (never
             silently overwritten). Optimistic "revision" check: a stale page
             cannot overwrite newer settings (409 -> "reload the page").
  Status   : Not created yet on your install -- it appears when you first save.

3. STABLE CAMERA KEY
--------------------------------------------------------------------------------
  "<nvr>:<channel>"  e.g.  nvr1:8 = NVR1 Cam 8,  nvr2:8 = Floor 10 - Reception.
  Built from the camera's real identity, never from its position in a list.
  The technical identity (NVR key, channel, technical name, RTSP path,
  credentials) is never modified; displayName/displayOrder are separate metadata.

7. ORDER BEHAVIOUR                                                       PASS
--------------------------------------------------------------------------------
  A display order is a POSITION. A camera given order N sits exactly at position
  N; cameras without an order fill the remaining positions in their original
  order. So "HR Office = 1, Reception = 2" works without renumbering the other
  23 cameras. The grid sorts by this order FIRST and then cuts pages:
  orders 1-6 = page 1, 7-12 = page 2, ... (verified).
  Drag-and-drop / "move here" set explicit positions for all cameras; ▲ ▼ swap
  two neighbours; "Reset order" makes one camera automatic again; "Reset all
  ordering" returns to the original order.
